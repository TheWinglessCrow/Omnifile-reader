Omnifile-Reader
_____________________________________________________________________________________________________________________________
A web-based application that allows you to be view files such as .ZIP, .RAR, CBZ, .JPG, .JPEG, .PNG, .GIF, .CHD 
using your browser without requiring the file to be opened in folder.
